## ⚡ Quick Start

Run any module using the Dart SDK (bundled inside Flutter):

```bash
# Run all Big O examples
dart run 01_big_o/main_big_o.dart

# Run Singly Linked List demo
dart run 02_data_structures/01_singly_linked_list.dart
```
